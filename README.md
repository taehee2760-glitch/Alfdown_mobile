# AlfDown Mobile 1.0 (Android)

AlfDown 5.4의 공개 S3 악보 이미지 검색 규칙을 Android Java 앱으로 구현한 프로젝트입니다.

## 기능
- 4개 악기군, 25개 악기 체크박스 및 그룹/전체 선택
- AC, BTX, BBC, BTC 포함. BTX는 SB처럼 파트 번호 없는 파일명
- 상품 번호, 최대 파트/페이지, 동시 검색 요청 수
- PNG/JPG/JPEG/WEBP 확장자 및 스코어 전용 검색
- HEAD 존재 확인, 403 구분, 발견 목록/진행률, 검색/다운로드 중지
- 선택한 Android 폴더(SAF)에 원본 이미지 저장, PDF 생성, 악기/파트/페이지 정렬
- 따뜻한 크림·베이지 계열 UI

## GitHub Actions로 APK 빌드
1. 새 GitHub 저장소를 만들고 **이 ZIP 내부 파일 전체를 저장소 최상위에** 업로드합니다. (기존 Windows AlfDown 저장소를 덮어쓰지 않는 것을 권장합니다.)
2. Actions → **Build AlfDown Android APK** → Run workflow를 선택합니다.
3. 성공한 실행의 Artifacts에서 `AlfDown-Mobile-debug-APK`를 받습니다.
4. ZIP을 풀고 `app-debug.apk`를 Android 기기에 설치합니다. 미확인 출처 설치 허용이 필요할 수 있습니다.

GitHub Actions의 Android SDK/Gradle 다운로드에는 네트워크가 필요합니다. 디버그 APK는 Google Play 배포용 서명 빌드가 아닙니다.

## 참고 및 제한
- 현재 소스와 빌드 설정은 제공되지만, 여기서는 Android SDK가 없어 실제 APK 빌드 및 실기기 테스트를 하지 못했습니다.
- Android 시스템 파일 선택기로 저장 폴더를 지정합니다. 기기에 따라 '저장 폴더 열기' 버튼의 지원 여부가 다릅니다.
- 검색 결과는 앱 실행 중 메모리에 유지됩니다. 앱을 종료하면 검색/다운로드 목록은 초기화됩니다. 파일은 선택한 폴더에 남습니다.
- PDF는 **현재 실행에서 다운로드 완료한 이미지**를 대상으로 만듭니다. 원본 이미지는 그대로 남습니다.
- PDF 페이지는 이미지의 원래 비율을 유지하며 최대 2000픽셀 크기로 축소될 수 있습니다.
- 검색 중지는 진행 중인 네트워크 요청이 타임아웃될 때까지 즉시 반영되지 않을 수 있습니다.
- 공개적으로 접근 가능한 이미지 파일만 조회합니다. 저작권/이용 조건을 확인하고 사용하세요.
